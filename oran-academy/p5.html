P5 — Cloud, OAM & Security
WG6 + WG11 · 6 blocchi · O-Cloud · ZTP · STRIDE
← P4 P6 HW →

Il modulo P5 copre O-Cloud (IMS/DMS), l'interfaccia O2 (FOCOM/NFO), Cloud Design con i 3 eliminatori, OAM/FCAPS/ZTP, e Security WG11 con STRIDE.

O-Cloud IMS/DMS
IMS gestisce infrastruttura fisica (Resource Pool). DMS gestisce NF deployment (Deployment Plane). Separazione netta — frecce O2-IMS e O2-DMS separate.
3 eliminatori Cloud
RT Kernel selezionabile · SR-IOV nativo · PTP out-of-band. Vendor cloud senza questi 3: escluso dal RFP vDU.
ZTP — Zero Touch
DHCP boot → NFO placement → DMS Helm deploy → O1 config → cell UP. Target: meno di 4 ore per sito. Zero interventi manuali.
Security WG11
STRIDE su O-Cloud. 8 vettori attacco. Zero trust: OAuth2.0 + mTLS su ogni interfaccia. Image signing obbligatorio supply chain.
La decisione più critica per un CTO O-RAN: non è "quale vDU scelgo" — è "quale cloud platform scelgo". Il cloud platform determina tutto: RT Kernel disponibile, SR-IOV, PTP, ZTP. Scegliere una piattaforma senza i 3 eliminatori blocca il deployment vDU.
