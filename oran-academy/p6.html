P6 — HW & Stack Reference
WG5 + WG7 + WG8 · 5 blocchi · COTS · AAL · GPU/FPGA · K8s
← P5 Dashboard →

Il modulo P6 copre l'architettura HW COTS, l'Acceleration Abstraction Layer (AAL), le soluzioni GPU/FPGA (FlexRAN/Aerial), il White Box O-RU, e lo stack software K8s/SR-IOV.

AAL — Acceleration Abstraction Layer
Strato software che disaccoppia il vDU dall'acceleratore fisico. AAL-FEC (Intel ACC100), AAL-LPU (L1 full), AAL-BFW (beamforming). Risparmio: -40/60% CPU load vDU.
Scelta acceleratore per sito
Rurale: CPU only · Urbano: CPU + FPGA ACC100 (FlexRAN) · Dense urban: CPU + GPU H100 (Aerial). AAL garantisce stesso vDU software su tutti e tre.
White Box O-RU
AMD Xilinx RFSoC (FPGA + ADC/DAC integrati). Vendor: Benetel, Foxconn, Compal, Sercomm. IQ compression obbligatoria per 64T64R (>25 Gbps raw).
Stack K8s + SR-IOV
CaaS Bare Metal · Multus CNI per multi-NIC · Flannel + SR-IOV · RT Kernel + CPU pinning · image signing Cosign per supply chain security.
Non esiste un solo acceleratore giusto per tutta la rete. Un operatore maturo usa CPU, FPGA e GPU in funzione del tipo di sito. L'AAL garantisce che lo stesso vDU software giri su tutti e tre senza modifiche al codice applicativo.
